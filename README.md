# Deadlight
Main source code for Deadlight.

The code does not work **as-is**, and may need some tweaking to get right. Any bugs in the original code remain unfixed, along with balancing problems. This was made using Eclipse's build system, using Spigot's 1.20.1 jar file. This relies on a bot plugin to also be present, and some features (or the entire plugin) may not work without it. Just remove any references to it, or replace them.

## Dependencies
- ProtocolLib
- Vault (along with some permissions plugin)
- Citizens (free works fine)
